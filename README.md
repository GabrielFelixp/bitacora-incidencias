# Bitácora de incidencias · app

Código de la app de registro de incidencias de producción (versión 3, GitHub).
Este repositorio solo contiene el código: **no tiene datos**. Las incidencias se
guardan en el repositorio privado de datos que se configura desde el botón
**Conexión** dentro de la app. El token de acceso se guarda únicamente en el
navegador de cada dispositivo.
